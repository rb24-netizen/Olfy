    04 / WHEN THE SENSOR ARRIVES

    Connect. Check. Then collect.

    Optional until delivery

    Hardware drivers are optional while you practice.

    Stop Olfy with Control + C, then run this in the extracted project folder. You can install drivers before delivery.

    bash start.sh --hardware

    BME688 setup is a specific USB breakout/bridge combination. A serial board must stream the Olfy packet format. Other sensor signals need their own adapter and measured references.

    1. Connect the physical device.BME688 breakout → QT cable → MCP2221 bridge → USB data cable → Mac.
    2. Open Lab in Real sensor mode.Choose the adapter, refresh devices and connect. Confirm the device ID and a changing resistance reading.
    3. Condition and warm up in clean air.Follow the supplied manufacturer guidance. A timer alone does not prove a stable baseline.
    4. Record one controlled reference.Choose a planned sample, enter its actual bottle ID, and record baseline → exposure → recovery.
    Open hardware controls ↗

    The USB prototype stays powered between scans. The consumer button starts recording; wireless wake-up needs accessory firmware and a transport implementation.

    KEEP THIS HANDY

    A clear next step, even when something fails.

    Olfy does not open

    Keep the launcher Terminal window open. Run bash start.sh --setup from the extracted project folder. If Python is missing, use the official macOS installer linked in Start_Here.html. If port 8765 is used by another app, try bash start.sh --port 8766 --setup.

    The sensor does not connect

    Check the selected adapter, optional drivers, a USB data cable, and the bridge/QT connection. Refresh devices. Choose an explicit serial port when more than one is listed. Open Lab for the connection error. The app stops on hardware errors rather than substituting generated readings.

    Training is not ready

    Use complete baseline/exposure/recovery references with compatible settings. Each known perfume needs at least three training exposures across two training days, and the separate held-out day must include every known label. A 10-second capture is not a reference scan. Lab → Recognize explains missing coverage.

    Updating or moving Olfy

    Finish recording and download a full backup. Keep your current data folder and replace application files around it, or restore the backup into a fresh data folder. Never put a blank exported database over your recordings. The experiment plan is included in the full backup.
